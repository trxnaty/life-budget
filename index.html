Field guide

How to use this ledger

  1. Set the plan. Click any number in the Plan column to edit it. Click a category name to rename it, or add lines with + Add line.
  2. Log reality. As the month unfolds, fill the gold Actual column. Everything above — the net figure, the mix, the bars — recalculates instantly.
  3. Read the bars. Each bar shows actual against plan. It turns red the moment a category runs over.
  4. Turn the page. Use ‹ › to move between months. A new month inherits your latest plan with a blank Actual column. The yearly chart fills in as months are logged.
  5. Chase the tick. The savings-rate meter carries a mark at 20% — the classic healthy target. Cross it and the meter lets you know.
  6. Sleep easy. Data lives only in this browser. Use Export backup for a portable copy.
